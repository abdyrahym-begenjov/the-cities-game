# the-cities-game
# The Cities Game (Игра в города) 🏙️

# English 
My first Python project. It's a classic city-building game where you enter a city name starting with the last letter of the previous city.

## Features:
* City database stored in **JSON** format.
* Lives system and scoring.
* Check for duplicates using `set`.
* Modern `match/case` syntax for ranking.
* Ranking system: At the end of the game, you receive stars based on your score.
* Error protection: The program trims spaces and corrects letter case.

## How to run:
1. Make sure Python is installed.
2. Download `The Cities Game.py` and `cities.json` to the same folder.
3. Run the script: `python "The Cities Game.py"`


# Русский
Мой первый проект на Python. Это классическая игра в города, где нужно вводить название города на последнюю букву предыдущего.

* Система жизней и подсчет очков.
* Проверка на повторы с помощью `set`.

* Защита от ошибок: Программа очищает пробелы и корректирует регистр букв.

## Как запустить:
1. Убедитесь, что Python установлен.
2. Скачайте `The Cities Game.py` и `cities.json` в одну папку.
3. Запустите скрипт: `python "The Cities Game.py"`
